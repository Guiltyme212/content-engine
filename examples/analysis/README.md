## The 3 structures we now own
- **A · Tip listicle** (`N. do X (benefit)`) — any niche
- **B · Symptom checklist** (`N) you feel X`) — problem-aware / emotional niches (the "you")
- **C · Personal story** (`N. I did X`) — transformation / aspirational (the "I")
